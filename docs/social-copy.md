### 正文

最近给 DeepSeek Harness 做了一个开源插件，把常用的供应商信息统一放进了侧边栏和设置页：

✅ DeepSeek 余额实时展示
✅ ChatGPT OAuth 授权登录
✅ ChatGPT 直接出现在 DSH 模型选择器里
✅ Plus/Codex 剩余额度进度条与重置时间
✅ CodexManager 切换账号后自动同步
✅ 侧边栏和设置页都支持「切换账号」
✅ 一键充值、打开 ChatGPT
✅ 中英文 README + 截图，MIT 开源

ChatGPT 额度不是简单显示“可用/不可用”，而是读取官方 Codex 用量接口，展示当前周期剩余比例。

项目地址：
https://github.com/CalvinQin/dsh-provider-balance-quota

一键安装：

```bash
curl -fsSL https://raw.githubusercontent.com/CalvinQin/dsh-provider-balance-quota/main/install.sh | bash
```

适合正在使用 DeepSeek Harness、CodexManager，或者想在一个工作台里切换不同模型的朋友。
